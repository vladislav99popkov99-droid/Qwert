# Мой календарь — обновлённая версия

Изменения:
- данные теперь хранятся в IndexedDB, а существующие записи из `localStorage` автоматически мигрируются;
- несколько независимых календарей: Любимый, Семья, Работа, Друзья;
- создание новых календарей;
- горизонтальное переключение календарей свайпом;
- резервная копия и восстановление JSON;
- PWA/service worker для офлайн-загрузки;
- разрешение на уведомления и напоминания о событиях;
- service worker уже умеет показывать входящие Web Push-сообщения.

## Важный момент про push

Полноценные push-уведомления, которые приходят на телефон, когда приложение закрыто, требуют Web Push backend и VAPID-ключи. В этом проекте клиентская часть и service worker подготовлены (`push` + `notificationclick`), но сервер отправки намеренно не содержит секретных ключей.

Таймер напоминаний в React работает, пока приложение открыто. Для production нужно подключить backend, который:
1. принимает push subscription;
2. хранит подписки пользователей;
3. отправляет VAPID/Web Push в нужное время;
4. удаляет недействительные subscriptions.

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
```

Для iPhone после публикации по HTTPS можно добавить приложение на экран «Домой». Это позволяет использовать PWA и Web Push при поддержке браузера.

## Восстановление старого календаря

При первом запуске новая версия проверяет старый ключ `my-calendar-entries-v1`. Если там есть данные, они автоматически переносятся в календарь «Любимый».

Дополнительно доступны кнопки «Резервная копия» и «Восстановить».
